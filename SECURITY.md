# Security

KEY is an active research and development project.

Security-sensitive reports should not be disclosed publicly before coordinated review.

For security reports, contact the project creator through the contact information listed in the main README.

When reporting an issue, include:

- affected component
- reproduction steps
- expected vs observed behavior
- potential impact
- relevant build/version information

KEY currently contains experimental and partial components. A verified micro-version does not imply that the entire project is production-ready or free of vulnerabilities.
