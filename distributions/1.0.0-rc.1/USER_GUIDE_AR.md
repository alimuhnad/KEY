# تجربة KEY Core 1.0.0-rc.1

هذه الحزمة تعمل على Windows x64، وتحتوي المترجم وأداة الأوامر وأمثلة قابلة للتعديل وتطبيق مخزون تجريبي. يسمح [ترخيص الحزمة](LICENSE.md) بالاستخدام المجاني للتعلم وبناء التطبيقات، بما فيها التجارية، وتوزيع برامجك المترجمة مع وقت التشغيل المضمّن. مصدر المترجم وملفات تطويره غير موزعة.

فك ZIP إلى مجلد قابل للكتابة، ثم افتح نافذة الأوامر داخله:

```bat
key.cmd version
key.cmd test
key.cmd run examples\core1\text.key
```

الأمر الأخير يطبع نصاً عربياً. بعض الأمثلة تختبر نتائجها باستخدام assert وتنتهي بنجاح دون طباعة نص.

## بناء برنامجك

احفظ هذا النص بترميز UTF-8 في `hello.key`:

```key
world Hello {
  action Main() {
    let message="Hello from KEY\n";
    unsafe {
      for i in 0..Int(text_len(message)) {
        sys_write_byte(text_byte(message,UInt(i)));
      }
    }
  }
}
```

```bat
key.cmd build hello.key -o hello.exe
hello.exe
key.cmd check hello.key
key.cmd fmt hello.key
```

`run` يبني البرنامج ويشغله. `check` يتحقق بالترجمة دون تشغيل. `fmt` يطبع التنسيق؛ `fmt hello.key --write` يحفظه في الملف. فشل البناء لا يستبدل المخرج السابق. `test` يشغّل قائمة الأمثلة المرفقة، ويمكن إعطاؤه ملفاتك: `key.cmd test first.key second.key`.

## أمثلة للبدء

| الملف | الاستخدام |
|---|---|
| examples/core1/text.key | النص الثابت UTF-8 وفهرسة البايتات |
| examples/core1/generics.key | معاملات الأنواع والدوال العامة والملكية |
| examples/core1/enums.key | enum وmatch الشامل |
| examples/core1/modules.key | استيراد وحدة واستعمال تعريفاتها العامة |
| examples/transactions.key | معاملات العالم والتراجع |
| examples/lifetime_resources.key | الموارد والتنظيف |
| examples/world_transfers.key | نقل الموارد داخل العالم |
| examples/simd.key | عمليات SIMD الموثقة |

المترجم يدعم أيضاً إخراج DLL وCOFF/OBJ؛ ربط OBJ ببرنامج مضيف يحتاج رابط ذلك المضيف. أمرَا generate وإعادة بناء المترجم الظاهران في مساعدة الأداة يحتاجان مصادر التطوير الخاصة، وهي غير موجودة في الحزمة العامة.

## تجربة المخزون

شغّل `inventory.cmd` ثم اكتب:

```text
add 101 20 5
move 101 1 2 7
list
save
quit
```

النتيجة المتوقعة للصنف 101 هي 13 و12 في المخزنين. شغّل التطبيق مرة أخرى واكتب `list` للتحقق من استعادة البيانات. تُحفظ `inventory.keydb` في مجلد العمل الحالي، ويحمي قفل العملية من تشغيل نسختين على البيانات نفسها. هذه تجربة للغة؛ استخدم بيانات اختبار. التطبيق قد يعرض رقم نسخته 0.12.1 داخل حزمة اللغة Core 1.

## الحدود والبلاغات

هذه نسخة مرشحة تجريبية وليست إصداراً مستقراً معتمداً. المصدر الآمن له قيود ملكية واستعارة؛ استخدام unsafe أو واجهات DLL الخاطئة قد يفسد العملية. لا مكتبة قياسية أو شبكة أو GUI أو مدير حزم مرفق. النصوص ثابتة وفهرستها بالبايت، والمعرفات ASCII، ولا نموذج تزامن أو استثناءات عامة. اقرأ [نتائج التحقق والحدود](VALIDATION.md).

للبلاغات العامة: [GitHub Issues](https://github.com/alimuhnad/KEY/issues). أرفق مثالاً صغيراً والأمر ورمز الخروج ورسالة KEY وإصدار Windows وبصمة المترجم من PACKAGE-MANIFEST.json، بعد إزالة البيانات الخاصة.
